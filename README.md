LMS платформа для просмотра курсов Scorm. Присутствует следующий функционал:
1. Регистрация и логин по email и паролю. В header после логина выводим email и кнопку "выйти".
2. Загрузка пакетов Scorm
3. Сохранение загруженных курсов.
4. Скачивание уже загруженного курса.
5. Под каждым загруженным курсом должно отображаться название, кнопка запуска и кнопка "скачать".
6. LMS должна читать и запускать Scorm пакеты версии 1.2 и 2004 (только для залогиненных пользователей)
7. Удаление загруженного курса.
